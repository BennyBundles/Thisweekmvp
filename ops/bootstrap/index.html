Required sequence

Safe staff setup

1. Create a real account in Account & Security, confirm its email, and enroll TOTP.
2. Configure THISWEEK_BOOTSTRAP_ADMIN_EMAIL as an Edge Function server secret for the intended initial administrator. The value is never returned to this page.
3. Sign in as that account, complete MFA to AAL2, then bootstrap the initial admin here.
4. Create separate named staff accounts and assign only the minimum required roles. Use distinct people/accounts for support and risk coverage when available.
5. Refresh/re-authenticate after role changes. Staff coverage alone does not verify the release gate; the Phase 34 manual staff-review evidence is still required.
